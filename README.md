# eliah.dev

Portfólio de uma página. HTML e CSS puros, sem JavaScript.

## Estrutura
- `index.html` — conteúdo
- `style.css` — estilos (Google Sans Flex auto-hospedada em `fonts/`)
- `favicon.svg`, `.nojekyll`

## Publicação
GitHub Pages, branch `main`, raiz do repo `eliah-dev.github.io`.
Domínio próprio: criar o arquivo `CNAME` só depois que o DNS apontar.

## Stickers
As calhas laterais (~21vw) existem para isso. Exemplo comentado no fim do `index.html`.
